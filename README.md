# Portfólio de Desenvolvimento Web Front-End

Este repositório contém o código-fonte do meu portfólio profissional e de 6 projetos demonstrativos desenvolvidos para exibição comercial.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Semântico e estruturado para acessibilidade e SEO.
- **CSS3**: Layouts baseados em Flexbox e CSS Grid, com variáveis customizadas para fácil manutenção.
- **JavaScript (Vanilla)**: Menu mobile, filtros dinâmicos, accordion de FAQ e navegação suave.

Nenhum framework ou biblioteca pesada foi utilizada para garantir carregamento instantâneo e pontuação máxima em testes de performance.

## 📁 Estrutura do Projeto
- `index.html`: Homepage do portfólio.
- `css/`: Arquivos de estilização.
- `js/`: Scripts interativos.
- `projetos/`: Páginas demonstrativas independentes com identidades visuais próprias.
